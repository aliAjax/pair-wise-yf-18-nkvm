# hxyfront-62006 珠宝镶嵌宝石分拣

源提示词编号：8

我需要一个面向珠宝镶嵌工作室的宝石分拣前端系统，可以记录宝石编号、种类、形状、克拉重量、尺寸、净度、颜色、切工、镶嵌位置和分拣状态。页面需要有分拣批次、尺寸筛选、镶嵌位置示意图、缺陷备注和按订单查看的宝石清单。

## 拣配流程（已实现）

1. **占用批次名额**：石库里的石头先「占用名额」进入分拣批次（可只占名额、暂不配单），批次满额后不能再占。
2. **配入订单**：已占名额的石头通过「配入」进入当前拣配单。
3. **撤单与换单**：已占用的石头不能直接改配；先「撤掉占用」回到石库（净度、尺寸等原始档案记录保留不变），才能重新占用并配到其他订单。
4. **结项拦截**：点「结项放行」时逐颗校验该订单石头的颜色与尺寸，不合格的石头会逐条列出并挡住结项；撤掉不合格石头、从石库补入合格替石（不足时可用「补录」新建石头档案）后才放行。
5. **实时计数**：批次余量、订单待配数（合格数/需求数）、缺陷条数、本批总克拉在每次占用、撤掉、换单、结项、补录后立即按当前存档重算。
6. **本地存档**：所有状态写入浏览器 `localStorage`，关掉页面再打开可以接着做；顶栏可一键恢复演示数据。

结项只按订单的颜色与尺寸要求校验；净度与缺陷备注作为石头档案保留，不参与拦截。
